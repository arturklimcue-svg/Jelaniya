# Вишлист вдвоём 🎁

Общий вишлист подарков для двоих: Telegram-бот + мини-приложение (WebApp).
Один вишлист на двоих — партнёр видит, что вы загадали, и наоборот.

## Возможности

- **Вишлист на двоих** — каждая карточка с фото, ценой, категорией и приоритетом
- **Куплено / Вручено** — отмечайте покупку и вручение, подарок уходит в историю с фото
- **«Мне тоже»** — скопируйте желание партнёра в свой список
- **Идеи подарков** — копилка + генератор идей для партнёра
- **Сюрприз** — скрыть покупку от получателя до указанной даты
- **Реакции** — ставьте ❤️/🔥 и видите, кто что хочет больше
- **Календарь дат** — дни рождения и праздники; бот пришлёт напоминание и открытку в день события
- **Голосовые пожелания** — запишите, что бы хотели
- **Рекап года** — статистика загаданного, купленного и вручённого
- **История подарков** — фото вручений
- **Уведомления в боте** — о новом желании, покупке и вручении
- **Добавление по ссылке** — перешлите боту ссылку на вещь, она попадёт в вишлист
- **Тёмная тема**, общий фон, категории, достижения, экспорт списка
- **Офлайн** — PWA/Service Worker, работа из кэша

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен от @BotFather"
export WEBAPP_URL="https://ваш-домен/"
python main.py
```

- `BOT_TOKEN` — токен бота
- `WEBAPP_URL` — публичный URL мини-приложения (кнопка меню бота)
- `PORT` — порт веб-сервера (по умолчанию 8080)
- `GITHUB_USER` — ваш ник для диагностики (необязательно)

Данные хранятся в `data.json`, загруженные фото — в `uploads/`.

## Как это работает

1. Два человека открывают бота — они становятся парой (первый — «solo», второй привязывается к нему).
2. Каждый загадывает подарки в мини-приложении; партнёр видит список и отмечает «куплено».
3. При вручении подарок с фото попадает в общую историю.

## API

Все эндпоинты принимают `initData` (Telegram WebApp) в query-параметре.

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/data` | весь общий список (вишлист, идеи, история, события, категории, фоны) |
| POST | `/api/items` | добавить подарок/идею (`kind: wishlist|ideas`) |
| PATCH | `/api/items/{id}`, `/api/ideas/{id}`, `/api/history/{id}` | изменить поля |
| POST | `/api/items/{id}/delete` | удалить |
| POST | `/api/items/{id}/copy` | «мне тоже» |
| POST | `/api/items/{id}/gift` | отметить вручение (переносит в историю) |
| POST | `/api/items/{id}/restore` | восстановить удалённое (отмена) |
| POST | `/api/ideas/{id}/to-item` | перенести идею в вишлист |
| POST | `/api/events`, `/api/events/{id}/delete` | события календаря |
| POST | `/api/categories`, `/api/categories/{name}/delete` | категории |
| POST | `/api/upload` | загрузка фото/аудио (лимиты, проверка магии, webp) |
| POST | `/api/background` · `/set` · `/{index}/delete` | общий фон |
| GET | `/api/diag` | диагностика авторизации |
